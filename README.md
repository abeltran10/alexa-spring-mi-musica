# ALEXA MI MUSICA

ALEXA MI MUSICA es una app para Alexa que reproduce canciones desde tu propia fonoteca.

# CÓDIGO

La app MI MUSICA utiliza una base de datos en la nube con Google Firebase (https://firebase.google.com/?hl=es) y almacenaje Google FireStorage (ahora de pago) para almacenar el mp3. Personalmente, utilizaba Ngrok (https://ngrok.com/) para exponer el ejecutable JAVA hacia el exterior, el enlace lo asociaba a la app en el Developer Console de Amazon (https://developer.amazon.com).

Deberas crear tu application.properties con las propiedades necesarias.
